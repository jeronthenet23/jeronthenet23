- 📺 **Sonarr / Radarr** — TV and movie management
- ⬇️ **SABnzbd** — usenet downloader
- 🏠 **Homebridge** — HomeKit bridge for smart home devices
- 🔔 **Notifiarr** — notifications
- 🐳 **Docker + Portainer** — container management
- 🌐 **UniFi** — network infrastructure
- 📷 **Bambu Lab H2S** — 3D printer with live camera overlay in UniFi Protect
